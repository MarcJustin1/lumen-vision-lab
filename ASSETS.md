# Interface assets

Both assets were generated with the built-in Image Gen tool for this redesign, visually inspected, and saved inside the project. The art direction comes from the user-supplied InboxxHQ screenshot. Logos, text, controls, and floating preview cards remain real interface components. Existing Lucide Aperture, image, flask, notebook, and scan icons suit the academic vision subject and are retained from the application.

## Blue glass tile background

File: [public/assets/blue-tiles.png](public/assets/blue-tiles.png)

Low contrast, diffuse studio light, softly blurred edges, orthographic view. Fill frame; no text, logos, icons, people, panels, UI cards, controls, or watermark.”
